# LUMÉ Beauty Studio

A responsive beauty salon website built with HTML, CSS, and JavaScript.

## Live Demo

[Visit LUMÉ Beauty Studio](https://vibhakumari7889-hub.github.io/Lume-Beauty-Studio/)

## About the Project

LUMÉ Beauty Studio is a fictional salon website created as a frontend portfolio project. It features an elegant design, service information, and an appointment enquiry form.

## Features

- Responsive layout for desktop and mobile screens
- Mobile navigation menu
- Beauty service cards with enquiry buttons
- Appointment enquiry form with input validation
- Preferred appointment date selection
- Interactive form confirmation
- Smooth scrolling between sections

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- `index.html` — Website structure and content
- `style.css` — Styling and responsive layout
- `script.js` — Navigation and form interactions

## Note

This is a portfolio demo for a fictional salon. Service descriptions and prices are illustrative. The appointment form does not send or store real bookings.
